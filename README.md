# DataMatrix Telegram Bot

Приложение на Python с графическим интерфейсом для запуска Telegram-бота, распознающего DataMatrix коды с помощью облачного сервиса Aspose Barcode Cloud (версия 25.10.0).

## Возможности

- Графическое приложение, запрашивающее токен Telegram-бота, Client ID и Client Secret Aspose при запуске.
- Полное логирование работы бота прямо в окне приложения.
- Распознавание DataMatrix кодов в изображениях, отправленных пользователями в Telegram.
- Админ-панель со списком пользователей и количеством их запросов.
- Скрипт сборки `.bat`, устанавливающий зависимости и собирающий исполняемый файл через PyInstaller.

## Требования

- Python 3.10+ установленный в системе и доступный в `PATH`.
- Учетная запись Aspose Cloud и пара ключей (Client ID и Client Secret).
- Токен Telegram-бота, полученный у [@BotFather](https://t.me/BotFather).

## Установка и запуск в режиме разработки

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python bot_app.py
```

После запуска появится окно, в котором нужно указать токен бота и ключи Aspose. Нажмите «Запустить бота», чтобы начать приём сообщений.

## Создание исполняемого файла (Windows)

В репозитории находится сценарий `build_bot.bat`, который:

1. Создаёт (при необходимости) виртуальное окружение.
2. Устанавливает все зависимости.
3. С помощью PyInstaller собирает `dist\datamatrix_bot.exe`.

Достаточно дважды щёлкнуть `build_bot.bat` или запустить его из командной строки:

```bat
build_bot.bat
```

Готовый exe-файл находится в каталоге `dist`. Его можно запускать на любой машине с Windows без предварительной установки Python.

## Использование бота

1. Пользователь отправляет фотографию или изображение с DataMatrix кодом.
2. Бот пересылает изображение в Aspose Barcode Cloud и получает результат распознавания.
3. Ответ возвращается пользователю в Telegram.
4. В админ-панели отображается список пользователей и количество их запросов.

## Примечания

- Для корректной работы требуется активная подписка на Aspose Barcode Cloud.
- Во время сборки через PyInstaller может потребоваться доступ в интернет для загрузки зависимостей.
- Логи доступны в текстовом поле основного окна приложения. Админ-панель открывается по одноимённой кнопке после запуска бота.
